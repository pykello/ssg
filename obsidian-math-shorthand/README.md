# Obsidian Math Shorthand

An Obsidian community plugin that virtually expands the SSG math shorthand language in Live Preview and Reading View. Notes remain unchanged; rendering uses Obsidian's bundled MathJax.

The global setting defaults to enabled. A note's last `<!-- ssg-math-shorthand: on/off -->` directive overrides it. Inline `$…$` and display `$$…$$` math are supported; `:::math` blocks are intentionally outside the MVP.
